# Store Listing Info

## Short Description (max 132 chars)
Choose how many Google search results to show per page (30, 50, 80, 100). All local, no data collection.

## Detailed Description

Set your preferred number of Google search results per page. Pick from 10, 20, 30, 40, 50, 60, 80, or 100 results.

Open the popup and select the number you want. The next search you run will show that many results on one page. No reloading, no extra tabs.

Works by loading additional result pages in the background and merging them into your current page. Everything stays local. Nothing gets collected or uploaded.

## Permission Justifications

- **storage**: Saves your chosen results-per-page setting so it persists between browser sessions and syncs across devices.

## Single Purpose
Let users choose how many Google search results appear per page.
